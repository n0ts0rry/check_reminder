# Check Instrument Reminder

A single Windows `.exe`, launched by Task Scheduler every 30 minutes, that dims all monitors and asks "Have you checked the instrument?". After Yes/No the user types their name, and the answer is logged to `instrument_check_log.csv` beside the `.exe`.

> **Note:** The code in this repository was generated by Claude (Anthropic's AI assistant, model Claude Opus 5.5) via Claude Code, from the design doc below.

See [the design doc](Check%20Instrument%20Reminder%20Design%20Doc.md) for details.

## Build
- **Locally:** double-click `build.bat` (needs Python 3). Output: `dist\CheckInstrumentReminder.exe`.
- **GitHub:** push the repo; the `Build` workflow uploads a zip with the `.exe`, `config.json` and install scripts under the run's Artifacts.

## Install
1. Copy `CheckInstrumentReminder.exe`, `config.json`, `install_task.bat`, `uninstall_task.bat` into a user-writable folder, e.g. `C:\Tools\CheckInstrumentReminder`.
2. Edit `config.json` as needed (`title`, `message`, `yes_text`, `no_text`, `overlay_opacity`, `name_prompt`, `save_text`).
3. Run `install_task.bat`. Remove with `uninstall_task.bat`.

## Develop
`python reminder.py` runs the prompt directly.
