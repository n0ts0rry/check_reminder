# Check Instrument Reminder

> **Note:** The code in this repository was generated by Claude (Anthropic's AI assistant, model Claude Opus 5.5) via Claude Code, from the [design doc](Check%20Instrument%20Reminder%20Design%20Doc.md).

A small Windows app that makes sure the instrument gets checked. Every 30 minutes it dims the whole screen and asks:

> **Have you checked the solvent levels on the instrument?**

The user can't carry on working until they answer:

- **Yes** → they type their name and click **Save**. The answer is logged and the screen is released.
- **No** → they're sent back to the question with a reminder to go and check. The prompt won't go away until they can honestly answer **Yes**.

Each confirmed check is written to `instrument_check_log.csv`, giving you an audit trail of who checked and when.

---

## How it works

```
Task Scheduler (every 30 min)
        │
        ▼
CheckInstrumentReminder.exe starts
        │
        ├─ Already a prompt open? ──► exit (prompts never stack up)
        │
        ▼
Dim all monitors + show the question
        │
   ┌────┴────┐
  No        Yes
   │         │
   │         ▼
   │   Enter name → Save
   │         │
   └─► back  ▼
     to   Write row to CSV → exit
  question
```

The app isn't running in the background. Windows Task Scheduler starts it, and it closes as soon as the check is logged, so it uses no memory between prompts.

## Building for Windows 7

A `.exe` built with a modern Python **will not start on Windows 7**. You'll see an error like *"api-ms-win-core-path-l1-1-0.dll is missing"*. That's because Python 3.9 and later dropped Windows 7 support. The Win7 build therefore uses:

- **Python 3.8.10**, the last Python release that runs on Windows 7
- **PyInstaller 5.13.2**, a version known to work with Python 3.8 and Windows 7

**Which one do I need, 32- or 64-bit?** On the Windows 7 PC, open *Start → right-click Computer → Properties* and look at **System type**.

**Option B (easiest):** download the `Win7-x64` or `Win7-x86` zip from GitHub Actions, as shown above.

**Option A: build on your own PC** (the build PC can be Windows 7, 10 or 11):
1. Install Python 3.8.10 alongside any other Python you have:
   - 64-bit: [python-3.8.10-amd64.exe](https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe)
   - 32-bit: [python-3.8.10.exe](https://www.python.org/ftp/python/3.8.10/python-3.8.10.exe)
2. Build:
   - 64-bit: double-click `build_win7.bat`
   - 32-bit: in a Command Prompt in this folder, run `build_win7.bat 32`
3. The output is `dist\CheckInstrumentReminder-Win7-x64.exe` (or `-Win7-x86.exe`). **Rename it to `CheckInstrumentReminder.exe`** before installing, because `install_task.bat` looks for that name.

**What the Windows 7 PC itself needs:**
- **Service Pack 1** (*Computer → Properties* should say "Service Pack 1").
- Update **KB2533623**. If the `.exe` reports a missing DLL, install this update (or the later KB3063858) from Microsoft.
- Nothing else. Python is still bundled inside the `.exe`, and installing works the same as below.

On Windows 7, screen scaling (DPI) support is more limited. If the dimmed overlay doesn't quite cover a scaled monitor, set display scaling to 100%.

## Step 2: Install on the target PC

1. Create a folder, e.g. `C:\Tools\CheckInstrumentReminder`.
2. Copy these four files into it:
   - `CheckInstrumentReminder.exe`
   - `config.json`
   - `install_task.bat`
   - `uninstall_task.bat`
3. (Optional) Edit `config.json` to change the wording. See below.
4. Double-click `install_task.bat`. You should see *"Task installed"*.
5. **Test it now:** open **Task Scheduler**, find **CheckInstrumentReminder**, right-click it and choose **Run**.

The 30-minute timer counts from when you installed the task, not from the top of the hour.

## Step 3: Read the log

Open `instrument_check_log.csv` (in the same folder) with Excel or Notepad:

| date | time | name | answer | windows_user |
| --- | --- | --- | --- | --- |
| 2026-11-18 | 09:30:12 | Jane Smith | Yes | jsmith |

- **name** is what the user typed.
- **windows_user** is the account that was logged in, so you can spot mismatches.
- If the folder isn't writable, the log is saved to `%LOCALAPPDATA%\CheckInstrumentReminder\` instead.

## Uninstall

Double-click `uninstall_task.bat`, then delete the folder.

## Customising the wording (`config.json`)

```json
{
  "title": "Instrument Check",
  "message": "Have you checked the solvent levels on the instrument?",
  "yes_text": "Yes",
  "no_text": "No",
  "overlay_opacity": 0.85,
  "name_prompt": "Please enter your name:",
  "save_text": "Save",
  "no_reminder": "Please check the instrument now, then answer again."
}
```

| Setting | What it changes |
| --- | --- |
| `title` | Heading at the top of the dialog |
| `message` | The question. Use `\n` for a line break |
| `yes_text` / `no_text` | Button labels |
| `overlay_opacity` | Screen dimming, from `0` (clear) to `1` (black) |
| `name_prompt` | Text above the name box |
| `save_text` | Label on the save button |
| `no_reminder` | Red message shown after clicking **No** |

Changes take effect on the next prompt. If the file is missing or has a mistake, the built-in defaults are used.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Prompt never appears | Check the task exists in Task Scheduler and that you're logged in. Missed runs during sleep are skipped. |
| *"api-ms-win-core-path-l1-1-0.dll is missing"* or the app won't start on Windows 7 | You're using the Win10/11 build. Use the Win7 build, and make sure SP1 + KB2533623 are installed. |
| *"Not a valid Win32 application"* | 64-bit `.exe` on 32-bit Windows. Use the `x86` build. |
| Antivirus blocks the `.exe` | A known false positive for unsigned PyInstaller apps. Ask IT to allow-list it, or code-sign it. |
| Need to close a stuck prompt | Ctrl+Shift+Esc → Task Manager → end **CheckInstrumentReminder**. |
| Log file not appearing | The folder may be read-only. Look in `%LOCALAPPDATA%\CheckInstrumentReminder\`. |

## Limitations

- **Not a hard lock.** Task Manager or an admin can always end it. That's deliberate for safety.
- **Lock screen (Win+L).** The prompt waits and appears when the PC is unlocked.
- **Honour system.** The name is typed, not verified, and the CSV can be edited. For a formal audit trail, store the log on a read-only or shared location.
